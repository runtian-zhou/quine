## Analysis

The single failure (`multi_tool_chain`) is caused by a conversation history bug in `crates/quine-core/src/engine.rs`. When the agent makes multiple sequential tool calls across turns (bash then read_file), each tool result is appended as a separate user-role `tool_result` message. The Anthropic Messages API requires all tool results from a single assistant turn to be batched into a single user message with multiple content blocks. The consecutive user messages cause a 400 "Improperly formed request" rejection. This is a known issue — the same failure occurred in the previous QA run. The fix requires grouping tool result messages into a single user message when they follow the same assistant tool_use turn in `engine.rs`.
