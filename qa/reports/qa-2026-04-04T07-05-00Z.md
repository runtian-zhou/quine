## Expected Runtime Checks

- Permission `ask` outcomes emit an approval interaction request with a
  permission-specific source label.
- `approve once` resumes the original tool execution and completes the turn.
- `deny once` clears the pending approval state and returns a deterministic
  permission denial.
- Harness subscribers receive the approval prompt and can resume the paused turn
  through `submit_interaction_response`.
