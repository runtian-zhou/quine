# Phase 1: Clarify the Feature Request

Before writing anything, make sure you understand what the user wants. Ask clarifying questions if the request is ambiguous. Specifically, nail down:

- **What** the feature does (user-visible behavior)
- **Why** it's needed (motivation, use case)
- **Scope boundaries** — what's explicitly out of scope
- **Breaking changes** — does this change any public API?

Once you have enough clarity, summarize the feature back to the user in 2-3 sentences and get confirmation before proceeding.

## Output

A confirmed feature summary that both you and the user agree on. This becomes the input for the Design phase.
